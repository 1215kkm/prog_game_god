# 신의 손길 (God Simulation Game)

전지전능한 시점에서 하늘 위에서 세상을 내려다보며, 자연을 통제하고 문명의 발전을 지켜보는 갓 시뮬레이션 게임입니다.

## 게임 소개

- **하늘에서 바라보는 세계**: 산, 바다, 숲, 초원으로 구성된 절차적 생성 맵
- **살아있는 주민**: AI로 자율 행동하는 사람들 (일하기, 먹기, 자기, 사교, 연애, 출산)
- **야생 동물**: 토끼, 사슴, 늑대, 곰, 새, 물고기 (생태계 시뮬레이션)
- **신의 권능**: 날씨 제어(비, 눈, 폭풍), 천둥번개, 지진, 축복, 역병, 기적
- **문명 발전**: 원시시대 → 석기 → 청동기 → 철기 → 중세 → 르네상스 → 산업 → 현대 → 미래
- **계절 시스템**: 봄/여름/가을/겨울에 따른 시각 변화와 게임플레이 영향

## 실행 방법

```bash
# 정적 파일 서버로 실행 (아무거나 선택)
npx serve .
# 또는
python3 -m http.server 8000
# 또는
php -S localhost:8000
```

브라우저에서 `http://localhost:8000` 접속

## 프로젝트 구조

```
prog_game_god/
├── index.html              # 메인 HTML
├── style.css               # 스타일시트
├── src/
│   ├── main.js             # 진입점
│   ├── core/
│   │   ├── constants.js    # 상수, 타입 정의
│   │   ├── game.js         # 게임 메인 루프
│   │   └── simulation.js   # 시뮬레이션 엔진 (자원, 기술, 문화)
│   ├── world/
│   │   └── world.js        # 세계 생성 (지형, 강)
│   ├── entities/
│   │   ├── entityManager.js # 엔티티 관리
│   │   ├── person.js       # NPC AI (상태 머신)
│   │   ├── animal.js       # 동물 AI
│   │   └── building.js     # 건물
│   ├── powers/
│   │   ├── weather.js      # 날씨 시스템
│   │   └── godPowers.js    # 신의 권능
│   ├── ui/
│   │   ├── renderer.js     # Canvas 렌더러
│   │   ├── camera.js       # 카메라 (이동, 줌, 터치)
│   │   ├── minimap.js      # 미니맵
│   │   └── uiManager.js    # HUD, 정보 패널
│   └── utils/
│       ├── noise.js        # Perlin Noise (지형 생성)
│       └── pathfinding.js  # A* 경로 탐색
└── assets/
    └── sprites/            # (향후) 스프라이트 에셋
```
