# 신의 손길 (God Simulation Game)

전지전능한 시점에서 하늘 위에서 세상을 내려다보며, 자연을 통제하고 문명의 발전을 지켜보는 갓 시뮬레이션 게임입니다.

**큰 모니터에 띄워놓는 디지털 수족관** + **인터랙티브 갓 게임** 두 가지 모드 지원.

## 게임 소개

- **하늘에서 바라보는 세계**: 산, 바다, 숲, 초원으로 구성된 절차적 생성 맵
- **살아있는 주민**: AI로 자율 행동하는 사람들 (일하기, 먹기, 자기, 사교, 연애, 출산)
- **야생 동물**: 토끼, 사슴, 늑대, 곰, 새, 물고기 (생태계 시뮬레이션)
- **신의 권능**: 날씨 제어(비, 눈, 폭풍), 천둥번개, 지진, 축복, 역병, 기적
- **문명 발전**: 원시시대 → 석기 → 청동기 → 철기 → 중세 → 르네상스 → 산업 → 현대 → 미래
- **계절 시스템**: 봄/여름/가을/겨울에 따른 시각 변화와 게임플레이 영향

## 실행 방법

```bash
# 정적 파일 서버로 실행 (아무거나 선택)
npx serve .
# 또는
python3 -m http.server 8000
# 또는
php -S localhost:8000
```

브라우저에서 `http://localhost:8000` 접속

## 두 가지 모드

### 게임 모드 (클릭으로 시작)
직접 신이 되어 세계를 통제합니다.

### 관상 모드 (A키로 시작)
큰 모니터/TV에 띄워놓는 **디지털 수족관**. 카메라가 자동으로 이동하며 문명의 발전을 보여줍니다.
- 자동 시네마틱 카메라 (인물 추적, 풍경 탐색, 마을 관찰)
- 한글 자막 오버레이 ("김민수(23세)이(가) 이웃과 대화를 나누고 있다")
- 60초 무조작 시 자동 전환
- 전체화면 지원 (F키)
